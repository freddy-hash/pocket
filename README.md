## Qué hace

Registra ingresos y gastos en dólares, sugiere la categoría de cada gasto automáticamente con machine learning, y muestra gráficos de en qué se gasta el dinero.

## Categorías de gasto

Comida y bebida, transporte, servicios, educación, salud, entretenimiento, ropa, y hogar con ahorro.
